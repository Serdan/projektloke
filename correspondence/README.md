# Correspondence

Project outreach and replies. This directory is **private by default** and its contents are ignored by Git except for this README.

Local structure:

- `contacts.md` — working contact list.
- `outreach-plan.md` — current outreach strategy.
- `drafts/` — unfinished correspondence.
- `sent/` — exact copies of sent messages.
- `received/` — replies and inbound correspondence.

Preserve dates and original wording. Do not publish private correspondence merely because it is relevant to the project.
