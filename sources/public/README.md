# Public source archive

Use this directory only for source files that we have deliberately decided are appropriate to redistribute in the public repository.

Typical candidates are public-domain or clearly redistributable official documents where preserving a local copy materially improves verifiability.

A source being publicly accessible on the web does **not** automatically mean we should republish its full contents here. When in doubt, preserve it privately under `../archive/` and publish only metadata/linkage through the site source registry.
