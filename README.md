# Projekt Loke

Projekt Loke documents the rise of bigotry in Denmark, with a primary focus on transphobia: its political organization, rhetoric, media treatment, activist networks, policy proposals, and international connections.

The project root contains both the public website and the working material behind it.

## Structure

- `site/` — public static website and site-specific assets/code.
- `research/` — working notes, timelines, dossiers, topic briefs, and analysis.
- `sources/` — source material, archived references, primary documents, and source indexes.
- `correspondence/` — outreach, replies, interview requests, editor contacts, and other project correspondence.
- `project/` — internal planning, methodology, editorial standards, task lists, and project administration.

## Principles

- Prefer primary sources wherever possible.
- Distinguish documented fact, interpretation, and inference.
- Preserve enough sourcing to make important claims independently verifiable.
- Track corrections and uncertainty rather than silently smoothing over them.
- Treat organized opposition to minority rights as a subject for investigation, not merely as one side of an abstract culture-war debate.
