# Projekt Loke brand assets

The approved L-rune concept, converted to standalone vector paths. The rune geometry has been straightened and the original wordmark silhouette traced. No external fonts or embedded raster images are required by the SVG files.

- `logo.svg` / `logo.png`: primary logo, transparent background. PNG is 2172 pixels wide.
- `logo-white.svg` / `logo-white.png`: white logo for dark backgrounds.
- `logo-mono.svg`: one-colour charcoal logo.
- `mark.svg` / `mark-white.svg`: rune alone, tightly framed, for headers.
- `icon.svg` / `icon-512.png`: square transparent icon.
- `favicon.svg` / `favicon.ico`: square icon on a warm paper tile, suitable for light and dark browser chrome. ICO contains 16, 32 and 48 pixel sizes.
- `favicon-16.png`, `favicon-32.png`, `favicon-48.png`, `favicon-192.png`, `favicon-512.png`: paper-backed icon sizes.
- `apple-touch-icon.png`: 180 pixel touch icon.

Colours: deep red #a72a2a, charcoal #181818, paper #f2efe8.
Keep the mark's proportions. Use the square icon for avatars and browser icons; use the primary logo on light backgrounds and the white logo on dark backgrounds.
