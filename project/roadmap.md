# Roadmap

## Current

- Establish the political sequence around B62, B12, B47 and B145.
- Map Dansk Regnbueråd, international links and parliamentary uptake.
- Build the first media corpus and rhetoric records.
- Keep the site generator and evidence model simple and validated.

## Next

- Expand the Danish media map beyond the initial Berlingske/Dorte Toft corpus.
- Research positive/countervailing voices and representation gaps.
- Archive fragile primary sources locally where appropriate.
- Build an outreach package for LGBT+ Danmark and selected editors/reporters.
- Add correction/change history to published records.
- Add explicit evidence-strength/provenance fields where useful.

## Later

- Search/filter over the generated public data index.
- Deployment automation.
- Structured correspondence log.
- Broaden beyond transphobia once the trans-focused methodology is mature.
